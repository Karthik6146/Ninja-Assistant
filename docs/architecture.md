# Architecture and extensions

React/TypeScript/Tailwind is built with Vite. FastAPI serves the built dashboard and JSON API on localhost. The API authenticates reads using a local token/header or HttpOnly same-site cookie. Mutations require the explicit token header; origins and Host headers are validated. No remote binding is used by the launcher.

SQLite WAL stores projects, jobs, preferences, audit events, approvals and publication reservations. A separate SQLite checkpoint database stores LangGraph workflow interrupts. Each project edit revision has its own graph thread; a changed revision invalidates the previous review. Long transcription and rendering run only in a separate worker, never inside HTTP handlers. One cross-process OS lock limits heavy media work to one worker. Heartbeats lease running jobs for 60 seconds. Expired leases retry up to three total attempts. Job-specific output names make local rendering repeatable. Review waits survive API restarts.

Original media is copied into managed project storage. The transcript is separately preserved; edits are JSON decision lists and captions use source time. Clips are concatenated in user order and captions are remapped onto output time. A saved low-resolution preview and exact revision review are mandatory for final rendering. ffprobe checks streams and duration; FFmpeg decodes final output before completion. Hardware encoders fall back to libx264. Hindi rendering depends on installed font glyph coverage.

Tools use subprocess argument arrays, bounded errors, timeouts and cancellation checks. No shell tool is exposed to models. `tools.Tool` defines schema, permission, timeout and audit contracts; implementations must apply the timeout to their actual operations. Optional Telegram/n8n/MCP transports should call this same boundary rather than bypassing API permissions. Do not automatically install community skills.

Research accepts only public HTTPS sources, validates every DNS address and pins a validated IP while checking the original TLS hostname. Redirects are rejected. Responses are bounded to 1 MB. Source text is untrusted, displayed as plain text and never routed into tools. URL extraction is a source notebook, not a fact-verification engine. Search-provider integration remains pending.

Ollama and OpenAI-compatible cloud adapters are text-only. Names are configured in environment variables. Cloud sharing requires `CLOUD_ENABLED=true` and deliberate provider selection. No recordings are sent through either chat adapter. Input is capped at 24000 characters and output at 1024 tokens; hard currency budgeting and provider-specific pricing are pending. Do not expose API keys or full provider error bodies to the UI.

External publication is not connected. Publication reservations and exact, single-use approval hashing are groundwork, not evidence of a working uploader. Never retry an ambiguous external side effect as a fresh request; record and reconcile remote identifiers first. Separate platform keys prevent one platform from affecting another.

Windows is the primary runtime. Media subprocesses are portable; worker locking has Windows and POSIX implementations. Speech sample creation uses Windows voices. Optional containers can run the media API/worker with mounted media volumes; they cannot directly inspect or manage the Windows host. Host management must remain in a narrow native permission-enforcing service.

Native jobs execute in cancellable child processes, with descendant cancellation. FFmpeg/ffprobe have media format and file/pipe protocol allowlists. Project edits and review writes use optimistic compare-and-swap checks; queued renders freeze the exact approved EDL. Coding uses separate Git branches/worktrees and source-path/credential-marker checks; tests execute trusted code natively only with snapshot-bound approval, a limited environment and time limits. Worktrees are not an OS sandbox. Model credentials are excluded from the test environment. The small candidate adapter validates all returned file names before writing; merge/push/install are absent. Candidate files need final human diff review.

Content packages preserve source edits/captions, per-platform copy/account label/media/schedule draft/review and scene manifests. Changing source revisions clears stale media/reviews. Platform copy edits invalidate only that platform; scene changes invalidate production reviews and stale audio/timing. No calendar executor or publishing/analytics adapter is installed. Manual handoff exports represent local preparation, never external execution.

Known hardening work: token/credential ACL management and keyring integration, tighter request-body admission limits, fully atomic coordination across separate API/job transactions, secure sandbox execution for third-party tests and redaction of arbitrary media/test error text. This is intended for trusted personal recordings/repositories on localhost, not hostile uploads or multi-user internet deployment.
